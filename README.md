# hidot.

QR で集まって、自分で作ったドット絵のキャラで、集合写真を撮るアプリです。

- App Store：https://apps.apple.com/jp/app/id6831123154
- ブラウザで試す：https://hidot.net

このリポジトリは**説明だけ**です。コードや設定は載せていません（理由は一番下にあります）。

## どんなアプリか

景色の写真に、みんなのドット絵のキャラが集まる集合写真を撮ります。ホストの QR を読めば、友達はアプリもログインもなしに、ブラウザで入れます。自分のキャラは自分しか入れられず、自分しか動かせません。

## 作った人と、AI の使い方

作品のコードは、主に Claude Code に書いてもらっています。自分の役目は、何を作るか、どこを直すか、本当に直ったかを確かめることです。一方、プログラミングの学習は、自分の手で進めています。（AI は解説の補助や、理解度チェックに使用しています）この説明に出てくる「なぜ」は、自分で決めたことです。

## 技術の選び方

| 決めたこと | 選んだもの | 理由 |
|---|---|---|
| 全体の形 | 画面とサーバーを分ける | キャラの絵・カメラ・合成など、ほとんどの仕事がスマホの中で終わる。サーバーの仕事は「部屋」だけなので、Rails でまとめるより形が合う |
| 画面 | React + TypeScript + Vite | 画面が増えていくので、状態の管理を React に任せる。ドット絵は canvas で描く |
| TypeScript | 画面とサーバーで、やりとりするメッセージの型を同じにする | 書き間違いが、動かす前に分かる |
| サーバー | Cloudflare（Workers） | 無料の枠から始められる |
| 部屋 | Cloudflare Durable Objects | 下で説明する |
| アプリ化 | Capacitor（iPhone・Android） | Web の作りをそのままアプリにできる |
| iPhone アプリの組み立て | Codemagic | **Mac を持っていなくても**出せる |

**比べてやめたもの**

- Firebase・Supabase：「自分のものだけ動かせる」をデータベースの決まりで書くことになり、匿名ログインが要る。ログインなしで使えることを守りたかった
- 自分で立てる Node.js のサーバー：ずっと動かす費用がかかる。無料の枠だと寝てしまう
- Rails の Action Cable：部屋の仕組みとしては、同じ理由で合わない

## 部屋の同期

「みんなが同時に自分のキャラを動かしても、取り合いにならず、他人のキャラは動かせない」を、どう作ったかです。

- **部屋1つ ＝ Durable Object 1つ。** 全員の接続がその部屋につながり、部屋は届いたメッセージを**1つずつ順番に**処理します。同時に動かしても順番がそろい、取り合いが起きません
- **「誰のキャラか」を、メッセージに書く欄を作らなかった。** サーバーは「どの接続から来たか」で持ち主を決めます。他人の id をわざと書いて送っても、無視されます（テストあり）
- **決まりを、Cloudflare の部品から分けた。** 部屋の決まり（入る・動かす・持ち主の確認）は、ただの TypeScript に分けて、サーバーなしでテストできるようにしました
- **届いたメッセージは、形と大きさを確かめてから使う**。送りすぎも防ぎます
- **切れてもつなぎ直せる。** スマホの画面を消すと接続は切れます。そのときキャラは消さず「いない」印にして、つなぎ直すと同じ位置に戻ります
- **費用を抑える。** だれも動かしていない間は、部屋をメモリから外せる仕組み（Hibernation）を使います。部屋は一時的なもので、時間がたつと閉じます。閉じると、中に入っていたキャラや位置の情報は消えます

## 作りながら学んだこと

- **使う人の環境で確かめる。** iPhone でだけ、看板の文字の下が切れました。パソコンのブラウザだけで確かめて、2回「直った」と言って外してしまいました。原因は、iPhone のブラウザが文字の高さを別の値で取ることでした。使う人と同じ環境で見ないと、確かめたことになりません
- **1人では使えないと広がらない。** みんなで集まって撮るアプリですが、集まる前の「最初の1人」が楽しめないと、広がりません。公開してから気づきました
- **数字から目をそらさない。** ストアのページを見た人のうち、どれだけの人が入ってくれたかを見て、次に直す場所を決めています
- **手持ちの道具で出す。** Mac がなくても、Web の作りをアプリにして、組み立てをクラウドに任せれば、iPhone アプリを出せます

## テスト

部屋の決まりをはじめ、主な処理にテストがあります。決まりを Cloudflare の部品から分けたので、サーバーなしでテストできます。
